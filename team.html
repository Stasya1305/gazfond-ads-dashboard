Источники данных и методика

Все выгрузки охватывают 01–30.09.2026 и получены 05.10.2026. План взят из прежнего дашборда и подтверждён пользователем. Выполнение плана = факт / план × 100%.

В исправленной выгрузке Директа столбец «Конверсии» относится к цели «Подписать договор» — подтверждено пользователем 05.10.2026. Строки объявлений сложены по ID кампаний, суммы сверены со строкой «Итого».

Метрика: атрибуция «Последний значимый переход (Кросс-девайс)». Сложены только конечные UTM-ветки; кампании сопоставлены по utm_campaign: brand, category, topup, segment, promo_x2. Общий итог файла оформления не подменяет сумму этих веток. Выгрузка «Личный кабинет» не содержит UTM-разбивки, поэтому конверсия по этой кнопке не рассчитана.

CTR = клики / показы × 100%. План по подписаниям — 820 конверсий рекламной цели; общий итог договоров ГАЗ ЭДО не прибавляется к ним.

Источники данных и методика

Выгрузки охватывают 01–07.10.2026, получены 07.10.2026. Последний день не завершён. Итог ГАЗ ЭДО — 107 договоров, предоставлен пользователем 07.10.2026. План ГАЗ ЭДО на октябрь — 1 000 договоров, предоставлен пользователем 07.10.2026. Выполнение = 107 / 1 000 × 100% = 10,70%; остаток до плана — 893 договора.

Яндекс Директ: показы, клики и столбец «Конверсии» сложены по ID кампаний и сверены со строкой «Итого». В командном отчёте используется согласованная цель «Подписать договор». CTR = клики / показы × 100%.

Метрика: атрибуция «Последний значимый переход (Кросс-девайс)». Лендинг содержит пять веток utm_campaign без детализации по utm_content. Оформление содержит 11 веток utm_content, которые сложены по соответствующим пяти кампаниям. Вложенные уровни повторно не учитываются. Полный состав источников остатка до общего итога оформления в выгрузке не раскрыт.

План на октябрь предоставлен пользователем 05.10.2026. Плановые кампании: все четыре поисковые кампании; план — 2 000 000 показов, 160 000 кликов, CTR 8%. Тестовые: «Акция Х2_РСЯ»; план — 1 000 000 показов, 30 000 кликов, CTR 3%. Выполнение по объёмам = факт / месячный план × 100%. CTR категории = сумма кликов / сумма показов × 100%; отклонение CTR = факт минус план в процентных пунктах. План по подписаниям рекламной цели не задан. Цель «Кнопка "Личный кабинет" Ландинг ПДС Яндекс»: сумма целевых визитов по дням. Выгрузка содержит только общий итог без UTM-разбивки, поэтому целевые визиты ЛК не распределяются по кампаниям и не прибавляются к визитам на оформление.
